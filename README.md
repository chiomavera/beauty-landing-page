# 💄 Beauty – Responsive Landing Page for a Beauty Salon

**Beauty** is a clean, user-friendly landing page built for beauty salons and wellness businesses. Designed with conversion in mind, the site highlights services, working hours, and a strong visual brand to turn visitors into paying clients.

👉 **Live Demo:** [https://beautybyverankanmuo.netlify.app/](https://beautybyverankanmuo.netlify.app/)

---

## 🎯 Project Goals
- Drive user engagement through a clean, elegant UI  
- Present services and working hours clearly and concisely  
- Offer intuitive navigation for potential customers  
- Design with mobile-first principles and responsiveness  

---

## 🛠 Tech Stack
- **HTML5** – Semantic, SEO-friendly structure  
- **CSS3** – Custom styling with media queries for responsiveness  
- **Bootstrap** – Grid layout and reusable components  
- **JavaScript (Vanilla)** – Interactivity and DOM behavior  
- **Netlify** – Deployment and hosting  

---

## 🌟 Features
- Responsive design for desktop and mobile  
- Scrollable sections with clean service breakdown  
- Highlighted working hours for easy booking consideration  
- Clear call-to-action areas for user conversion  

---

## 🧠 What I Learned & Built

This project allowed me to:
- Design with **user conversion goals** in mind  
- Apply **Bootstrap** for layout and styling efficiency  
- Practice **responsive design techniques**  
- Create an experience aligned with modern business landing pages
